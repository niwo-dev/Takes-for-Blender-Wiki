    Roadmap¶

    How to read the board

    • Hover an item's name for its checklist — done, open
    • Hover the info icon for what an item does
    • Hover the clock for when it was filed, started and shipped
    • Progress counts that checklist — ticked / total, and the share done
    • Click Type, Item, Progress or When to sort a table
