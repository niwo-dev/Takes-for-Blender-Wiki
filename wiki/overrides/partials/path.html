{#- Override of Material's breadcrumb partial. Two changes. 1. Stock Material renders only the ancestor path ("Home > What's New") and leaves the current page out. We append it as a final, non-link crumb, so the trail reads "Home > What's New > Roadmap". 2. A section crumb is a link ONLY when the section owns a page. Material's own macro links every section to whichever child comes first, which said "Features" and went to Variant Switch -- a lie about where you are. That used to be undone in JavaScript, by stripping the link off every crumb but Home; which then also stripped it off the sections that DO own a page, so "Course" was dead text and the only way back to the course was the home page or the drawer. The template knows the answer the DOM cannot: `first.is_index` is true exactly when the section's first child is its own `index.md`. So Course, Preferences and What's New link to themselves, and a group with no page of its own renders as plain text. -#} {% macro crumb(nav_item) %} {%- set first = (nav_item.children | first) if nav_item.children else none -%}
