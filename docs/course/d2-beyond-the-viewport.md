# D2 · Beyond the viewport

2 lessons · 9 min · the idea here is that **Takes follows you into other editors**.

## 1. The sequencer shows the right take <span class="tks-min">5 min</span> { #1-the-sequencer-shows-the-right-take }
<div class="tks-video" data-video="D2.1">Video Sequencer shows the wrong take? Playhead follow explained</div>

A scene strip points at a scene, and that scene has takes. Takes applies the strip's take as you scrub, so the preview is the edit.

Read more: [Video Sequencer](../features/sequencer.md)

## 2. Tools that stop resetting <span class="tks-min">4 min</span> { #2-tools-that-stop-resetting }
<div class="tks-video" data-video="D2.2">Snap settings reset when you switch scenes? Viewport Sync</div>

Blender stores snap and pivot per scene, so every switch swaps your toolbox. Sync mirrors them, so you set them once for the file.

Read more: [Viewport Sync](../features/viewport_sync.md)
