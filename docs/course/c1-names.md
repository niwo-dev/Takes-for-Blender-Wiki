# C1 · Names

5 lessons · 23 min · the idea here is that **your names write your folders**.

## 1. Filenames that write themselves<span class="tks-min">5 min</span>

<div class="tks-video" data-video="C1.1">Filenames that write themselves: Smart Output tokens</div>

Write the pattern once. Every render fills in the current scene, layer, take, camera and frame. Each field previews the real name.

Read more: [Smart Output](../features/smart_output.md)

## 2. Building a path by clicking<span class="tks-min">4 min</span>

<div class="tks-video" data-video="C1.2">How to build an output path by clicking: Build Syntax</div>

Click tokens into a pattern, move the chips, then click Apply. A directory has to start with two slashes or a full drive path.

Read more: [Name Your Output Files](../workflows/name_output_files.md)

## 3. Versions, separators and brackets<span class="tks-min">4 min</span>

<div class="tks-video" data-video="C1.3">Render versions, separators and bracket styles</div>

Use the version token for the render number and the separator token instead of typing underscores. Seven bracket styles, your pick.

Read more: [Smart Output](../features/smart_output.md#token-syntax)

## 4. Naming templates<span class="tks-min">5 min</span>

<div class="tks-video" data-video="C1.4">Your names become your folders: naming templates explained</div>

Smart Output names your files. Naming templates name your data: every action, slot, camera, take and preset Takes makes for you.

Read more: [Syntax Preferences](../preferences/workflow.md#syntax)

## 5. Your first custom token<span class="tks-min">5 min</span>

<div class="tks-video" data-video="C1.5">How to make your own token: the focal length in the filename</div>

Pick a source, say what to read, give it a name. Then your token works in any path like a built-in one. No scripting.

Read more: [Custom Tokens](../features/custom_tokens.md)
