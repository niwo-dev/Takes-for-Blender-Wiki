# C2 · Batch render: every shot at once

5 lessons · 23 min · **One click renders every shot**.

## 1. A shot did not render? The switch that decides <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #1-a-shot-did-not-render-the-switch-that-decides }
<div class="tks-video" data-video="C2.1">Why did my layer not render? The render toggle, not the selection</div>

Batch render follows the render icon on each row, not what is selected or active. Shift+click the icon to switch a whole scene at once.

Read more: [Batch Render](../features/batch_render.md#what-gets-rendered)

## 2. Render in the background and keep working <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #2-render-in-the-background-and-keep-working }
<div class="tks-video" data-video="C2.2">Batch render in Blender or in the background - keep working while it renders</div>

In Blender shows every frame but locks Blender until it finishes. In Background saves the file once and renders out of sight, so you keep working.

Read more: [Batch Render Your Takes](../workflows/batch_rendering.md)

## 3. Render only some shots, or only the failed ones <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #3-render-only-some-shots-or-only-the-failed-ones }
<div class="tks-video" data-video="C2.3">Render this scene, all scenes, by tag, resume, or retry failed</div>

The render menu offers this scene, all scenes, one chosen scene, or one tag. Finished shots are skipped, so a stopped run picks up where it left off.

Read more: [The Render Menu](../features/batch_render.md#the-render-menu)

## 4. The render queue, and a time estimate you can trust <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #4-the-render-queue-and-a-time-estimate-you-can-trust }
<div class="tks-video" data-video="C2.4">Reading the render queue and getting a real time estimate</div>

Every shot shows its status, from Pending to Done or Failed. The queue also warns about shots with no camera before the long render starts.

Read more: [Render Queue](../features/batch_render.md#render-queue)

## 5. Stop new renders overwriting old ones <span class="tks-min">6 <span class="tks-min__u">min</span></span> { #5-stop-new-renders-overwriting-old-ones }
<div class="tks-video" data-video="C2.5">Render versioning: v001, sub-versions, lock as final, archive old renders</div>

A version and sub-version number go into every file name. Add a note about what changed, and lock a version as final so it is never overwritten.

Read more: [Versions](../features/batch_render.md#versions-sub-versions-notes)
