# A6 · Modes that keep your scene steady

5 lessons · 26 min · **Stop things moving when you do not want them to**.

## 1. Rest State: why objects jump back <span class="tks-min">6 <span class="tks-min__u">min</span></span> { #1-rest-state-why-objects-jump-back }
<div class="tks-video" data-video="A6.1">Rest State explained: why unkeyed values snap back at frame 0</div>

Anything you have not keyed on a shot returns to its resting value when you switch. That is on purpose: every shot starts from the same clean baseline.

Read more: [Rest State](../features/rest_state.md)

## 2. Still or Animation: keep a still image still <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #2-still-or-animation-keep-a-still-image-still }
<div class="tks-video" data-video="A6.2">Still Mode vs Animation Mode - product stills that never scrub</div>

Still Mode pins a shot to frame 0, so a product still never renders from the wrong frame. Set it once for the whole project, then let single shots switch back to Animation.

Read more: [Still Mode](../features/still_mode.md)

## 3. Value Lock: stop changing values by accident <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #3-value-lock-stop-changing-values-by-accident }
<div class="tks-video" data-video="A6.3">How to stop changing values by accident: Value Lock</div>

One click stores every unkeyed value in the scene, from light power to material roughness. Nudge one by accident and it snaps straight back. Keyframed values stay free.

Read more: [Value Lock](../features/value_lock.md) · [Lock a Value](../workflows/lock_a_value.md)

## 4. Diff State: see what is animated at a glance <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #4-diff-state-see-what-is-animated-at-a-glance }
<div class="tks-video" data-video="A6.4">Diff State: see which objects are keyed, inherited or drifted</div>

Colours every object by where its values come from: blue if this take keys it, pink if a level above does, teal if nothing does, orange if it has drifted. Nothing in the file changes.

Read more: [Diff State](../features/diff_state.md)

<div class="tks-video" data-video="A6.5">The seven mode buttons, and which ones cancel each other</div>

Rest, Still, Value Lock, Autokey, Timeline, Variant Live and Diff State. What each one does while it is on, and which ones take turns so they never fight.
