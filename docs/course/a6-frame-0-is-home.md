# A6 · Frame 0 is home

5 lessons · 26 min · the idea here is that **frame 0 is home, and modes take turns**.

## 1. Rest State<span class="tks-min">6 min</span>

<div class="tks-video" data-video="A6.1">Rest State explained: why unkeyed values snap back at frame 0</div>

Your neutral baseline lives at frame 0. Key a value and the old one is mirrored there first. Switch away and unkeyed values return to it.

Read more: [Rest State](../features/rest_state.md)

## 2. Still or Animation<span class="tks-min">5 min</span>

<div class="tks-video" data-video="A6.2">Still Mode vs Animation Mode - product stills that never scrub</div>

Still pins a take to frame 0, the same frame the baseline lives on. Set the project to Still and let the turntable layer animate.

Read more: [Still Mode](../features/still_mode.md)

## 3. Value Lock<span class="tks-min">4 min</span>

<div class="tks-video" data-video="A6.3">How to stop changing values by accident: Value Lock</div>

It captures every unkeyed value in the scene and snaps back anything you nudge. Keyed and driven values stay free.

Read more: [Value Lock](../features/value_lock.md) · [Lock a Value](../workflows/lock_a_value.md)

## 4. Diff State<span class="tks-min">5 min</span>

<div class="tks-video" data-video="A6.4">Diff State: see which objects are keyed, inherited or drifted</div>

Four colours for where a value comes from: this take, a level above, the rest baseline, or drifted away from it.

Read more: [Diff State](../features/diff_state.md)

## 5. The mode row<span class="tks-min">6 min</span>

<div class="tks-video" data-video="A6.5">The seven mode buttons, and which ones cancel each other</div>

Seven modes, four pairs that cannot both be on. A greyed-out button is usually another mode holding it, not a fault.

Read more: [The Modes](../features/modes.md)
