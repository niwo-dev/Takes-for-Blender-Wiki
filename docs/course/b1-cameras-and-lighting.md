# B1 · Cameras and lighting

5 lessons · 23 min · the idea here is that **a shot is a camera and a light, per level**.

## 1. One camera per take <span class="tks-min">4 min</span> { #1-one-camera-per-take }
<div class="tks-video" data-video="B1.1">One camera per take - how to add and switch cameras</div>

<div class="tks-video" data-video="B1.2">Too many cameras in the viewport? Isolate: Single or Multi Camera</div>

## 3. Cutting between cameras <span class="tks-min">6 min</span> { #3-cutting-between-cameras }
<div class="tks-video" data-video="B1.3">How to cut between cameras inside one take: Multi-Cam</div>

A cut is a marker with a camera on it, and the take owns its own list. It needs a take that animates.

Read more: [Multi-Cam](../features/multi_cam.md)

## 4. Three lighting setups in one file <span class="tks-min">5 min</span> { #4-three-lighting-setups-in-one-file }

A world is a cascade value like any other. Give each layer its own, or set one on a group and let its layers share it.

Read more: [The Cascade](../features/cascade.md) · [Which Tool for the Job](../features/which_tool.md)

Preview draws a thumbnail beside each row. Preload builds the layers in the background so the first switch is instant. Different features.
