# A2 · Install and look around

4 lessons · 19 min · the idea here is that **your scene is a tree**.

## 1. Install it<span class="tks-min">3 min</span>

<div class="tks-video" data-video="A2.1">How to install Takes for Blender (and which Blender version you need)</div>

Blender 5.0 or newer. Install the ZIP without unpacking it, then find the **Takes** tab in the sidebar.

Read more: [Install Takes](../getting_started/installation.md)

## 2. A tour of the interface<span class="tks-min">7 min</span>

<div class="tks-video" data-video="A2.2">A tour of the Takes UI: header, tabs, tree, Inspector, Globals</div>

One pass over everything: the mode row, the warning badges, the four tabs, the tree and its buttons, and the parts that live outside the sidebar.

Read more: [Navigation Panel](../interface/navigation_panel.md)

## 3. Reading a tree row<span class="tks-min">5 min</span>

<div class="tks-video" data-video="A2.3">How to read the Takes tree - the nine icons on every row</div>

Every row carries the same strip of icons. Bright means set here. Dimmed means it came from a level above.

Read more: [Navigation Panel](../interface/navigation_panel.md)

<div class="tks-video" data-video="A2.4">Scene, View Layer, Take: the six levels explained</div>

Global, Scene Group, Scene, View Layer Group, View Layer, Take. A deeper level always beats a wider one.
