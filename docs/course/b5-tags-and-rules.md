# B5 · Tags and rules

3 lessons · 13 min · **Labels that sort, filter and set things for you**.

## 1. Tag your shots, then render only some <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #1-tag-your-shots-then-render-only-some }
<div class="tks-video" data-video="B5.1">How to tag takes, filter the tree and render by tag</div>

Make coloured tags, put them on scenes and View Layers, and filter the tree to one tag. Select Tag in the render menu renders only the shots that carry it.

Read more: [Tag & Filter Takes](../workflows/tag_and_filter.md) · [Tag Library](../features/tags.md)

## 2. Rules: one tag, a whole set of settings <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #2-rules-one-tag-a-whole-set-of-settings }
<div class="tks-video" data-video="B5.2">Rules explained: one tag that applies five presets at once</div>

A rule is a tag that carries presets. Put an Output rule on a group, and its render, output, file and colour settings all apply at once.

Read more: [Rules](../features/rules.md)

## 3. Let a tag pick the camera and the lighting <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #3-let-a-tag-pick-the-camera-and-the-lighting }
<div class="tks-video" data-video="B5.3">Let a tag pick the camera and world: Camera and Studio rules</div>

A Camera rule picks the camera and its lens preset. A Studio rule picks the world. Tag a shot, and its camera and lighting follow the tag.

Read more: [Rules](../features/rules.md)
