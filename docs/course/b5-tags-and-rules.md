# B5 · Tags and Rules

3 lessons · 13 min · the idea here is that **a label can do work for you**.

## 1. Tag, filter, render<span class="tks-min">4 min</span>

<div class="tks-video" data-video="B5.1">How to tag takes, filter the tree and render by tag</div>

Tags are colour labels. The funnel narrows the tree to one tag, and the render menu can render only the layers carrying it.

Read more: [Tag & Filter Takes](../workflows/tag_and_filter.md) · [Tag Library](../features/tags.md)

## 2. Rules are tags that work<span class="tks-min">5 min</span>

<div class="tks-video" data-video="B5.2">Rules explained: one tag that applies five presets at once</div>

A rule bundles preset assignments under one name. Apply it on any level and every preset inside it activates together.

Read more: [Rules](../features/rules.md)

## 3. Letting a tag pick camera and world<span class="tks-min">4 min</span>

<div class="tks-video" data-video="B5.3">Let a tag pick the camera and world: Camera and Studio rules</div>

A Camera rule chooses the camera preset and the camera object. A Studio rule chooses the world. You stop assigning them by hand.

Read more: [Rules](../features/rules.md)
