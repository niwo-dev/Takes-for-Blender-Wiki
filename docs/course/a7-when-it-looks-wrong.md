<div class="tks-video" data-video="A7.1">What the warning badges mean, and the fix button behind each</div>

An object jumped, a value keeps moving, the timeline will not play. For each symptom, the one panel or setting to look at first.

## 3. Use Takes on a file you already have <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #3-use-takes-on-a-file-you-already-have }
<div class="tks-video" data-video="A7.3">How to open an existing project in Takes: Keep It All or Decide One by One</div>

Open an older project and Takes asks one question about the animation, worlds and cameras it found. Keep It All leaves everything as it was. Decide One by One lets you sort each item.
