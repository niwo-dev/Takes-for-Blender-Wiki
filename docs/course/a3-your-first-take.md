# A3 · Your first take

4 lessons · 19 min · **Try a new idea without losing the old one**.

## 1. Your first two takes: two camera angles <span class="tks-min">6 <span class="tks-min__u">min</span></span> { #1-your-first-two-takes-two-camera-angles }
<div class="tks-video" data-video="A3.1">How to make your first take - two camera angles, one click to switch</div>

Start from Blender's default file, add a take with the + button, give each take its own camera, and flip between them. About ten minutes, start to finish.

Read more: [Your First Take](../getting_started/first_take.md)

## 2. Handle client feedback without losing versions <span class="tks-min">5 <span class="tks-min__u">min</span></span> { #2-handle-client-feedback-without-losing-versions }
<div class="tks-video" data-video="A3.2">How to run a review loop in Blender: notes and New Take from Here</div>

Write the client's note on the take, click New Take from Here, and work the change in. Take 1 stays one click away if the client changes their mind.

Read more: [Takes - the Review Loop](../features/vl_versions.md) · [Switch Between Takes](../workflows/switch_takes.md)

## 3. Take or View Layer: which one do you need? <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #3-take-or-view-layer-which-one-do-you-need }
<div class="tks-video" data-video="A3.3">Take or new View Layer? How to decide</div>

A take is another round of the same shot. A new View Layer is for when objects appear or disappear, or the motion changes. Two questions settle it.

Read more: [Which Tool for the Job](../features/which_tool.md)

## 4. Rename, reorder and delete takes safely <span class="tks-min">4 <span class="tks-min__u">min</span></span> { #4-rename-reorder-and-delete-takes-safely }
<div class="tks-video" data-video="A3.4">How to rename, reorder, duplicate and delete takes safely</div>

Every take shows a number and a name, like Take 3 · Night. The number is only the order and the name is what Takes goes by, so reordering never breaks anything.

Read more: [Context Properties](../interface/context_properties.md)
