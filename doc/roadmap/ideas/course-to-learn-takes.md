# A Course to Learn Takes

**Type:** Docs · **Theme:** Docs · **Area:** Course · **Size:** 🔴

Give the wiki an ordered course, so a newcomer is led from a first take to a finished render instead of meeting the pages one at a time.

## Phases

- [ ] Agree the spine — the handful of ideas a reader has to understand, and the order they should meet them in
- [ ] Settle the module and lesson list, built on the pages that already exist
- [ ] Give the wiki a Course section in the menu, and a way for a page to carry a video
- [ ] Publish the core stage: install, the first take, the cascade, actions, and what frame 0 is for
- [ ] Publish the looks-and-shots stage: cameras, variants, tags and presets
- [ ] Publish the shipping stage: names that write themselves, batch render, and one whole product end to end
- [ ] Publish the optional stage: hotkeys and pies, the sequencer, the assistant
- [ ] Point every feature page at the lesson that teaches it
