# Wiki roadmap — the wiki's OWN work

> [!IMPORTANT]
> **`doc/` and `docs/` are different things here, and mixing them up writes into
> build output.**
>
> | Path | What it is | Tracked? |
> |------|------------|----------|
> | `doc/roadmap/` | **This.** The wiki repo's own development roadmap — theme rebuilds, navigation, page accuracy. Hand-written. | yes |
> | `docs/roadmap/` | The **add-on's** public board, shown to readers. Generated by CI from `Takes-for-Blender/doc/roadmap/` on every push. | no — gitignored |
>
> One letter apart. Never hand-edit `docs/roadmap/`: it is regenerated on every
> deploy, so an edit there is thrown away without a word.

## How it works

Status is **the folder a card sits in** — no front matter, nothing to keep in sync.

```
doc/ROADMAP.md        ← the GitHub board, generated
doc/roadmap/
  ideas/    parked backlog
  active/   working now (max 3)
  done/     finished
  _dev/     technical notes; never published
```

Edit a card, then run:

    roadmap-build

That regenerates `doc/ROADMAP.md`. The pre-commit hook in `dev/hooks/` does it
for you whenever a commit touches a roadmap file — arm it once per clone with
`git config core.hooksPath dev/hooks`.

`roadmap-build` comes from `_tools/blender-repo-tools`:

    pip install -e ../_tools/blender-repo-tools

## What belongs here — and what does not

Here: anything about the wiki **as a product** — its theme, navigation, page
structure, whether a page tells the truth about the add-on.

Not here:

- **Add-on features.** Those live in `Takes-for-Blender/doc/roadmap/` and reach
  this repo only as the generated public board.
- **Screenshots.** Capturing and publishing the manual's images is WikiShot's
  job: see *Shoot the Takes Wiki* in `WikiShot-for-Blender/doc/roadmap/ideas/`.

## Card format

`# Title`, then a category line, a one-line description, then `## Phases` as
checkboxes:

```markdown
# Some Wiki Job

**Theme:** Docs · **Area:** Navigation · **Size:** 🟡

One plain sentence saying what a reader gets out of it.

## Phases

- [ ] First step
```

Size is required — it feeds a column on the board. 🟢 Small · 🟡 Medium · 🔴 Large.
